# 3D-анатомия поз FYSM

Интерактивная 3D-анатомия поз йоги: шесть основных асан, 24 положения FYSM, переходы между ними, мышцы, связки, суставы и фасции. Статические нагрузки являются оценками модели; новые переходы показывают геометрию без расчёта сил. Одна HTML-страница на three.js.

- Сборка: `python3 build.py` → `dist/index.html`.
- Автопубликация: при каждом изменении в `main` страница выкладывается на GitHub Pages.
- Инструкция для агентов и правила работы: `AGENTS.md`. Технические решения: `docs/tech-decisions.md`. История изменений: `CHANGELOG.md`.
- Новые переходы, формы дисков, сборка и ограничения: [docs/transitions.md](docs/transitions.md).
- Первичные исследования 2025–2026, что из них использовано и что не проверено: [docs/research-2025-2026.md](docs/research-2025-2026.md). Усилия — оценки общей модели; диапазоны на странице сравнивают два расчётных сценария и не являются персональной точностью.

Кости, исходные формы большинства мышц и 23 межпозвонковых дисков: BodyParts3D, The Database Center for Life Science (DBCLS), лицензия CC BY 4.0. Подгонка к общему ригу и деформация поверхностей остаются приближениями.
